# ClimaFit — Kotlin / Jetpack Compose のUIプロトタイプ

**フロントエンドの画面と表示操作だけ**を実装したAndroid Studioプロジェクトです。API通信・AI判定・服装提案の生成・不快指数の計算・データの保存は実装していません。画面内の会話も固定サンプルです。

## Android Studioで更新する

1. `settings.gradle.kts` がある **`codex_test` フォルダー**を開きます。
2. **Git → Pull** で `main` を更新します。再クローンは不要です。
3. 必要なら **File → Sync Project with Gradle Files** を実行します。
4. 上部で `app` と端末を選び、▶ Run を押します。

Android Studio Otter 3に対応。初回同期にはネット接続、JDK 17以上、Android SDK Platform 35が必要です。Gradle 8.11.1 / Android Gradle Plugin 8.9.2 / Kotlin 2.1.20 / Compose BOM 2025.03.01 / min SDK 26。

## 画面

- **提案**：写真付きの服装提案を上部に大きく配置。行き先は図書館・201教室・学生食堂・実験室3。「図書館の室温」など場所名に連動する見出しと「金沢の気温」を表示。
- **コーデAI**：最初に「写真でコーデ診断」「AIにコーデを提案してもらう」の2つから選択。それぞれ独立した会話画面へ進み、左上の戻るボタンまたはAndroidの戻る操作で選び直せます。写真・文章で相談するチャット画面。カメラ起動、写真選択、添付解除、吹き出し、保存ボタンの表示。入力すると画面内に自分のメッセージと固定サンプル応答を表示します。写真・文章の送信や保存は行いません。
- **気温別コーデ**：生成したコーデ写真2枚を同梱。「すべて」「今の金沢」「今の室温」「温度を指定」でサンプル一覧を絞り込み。金沢の気温・室温の両方をカードに表示。「今の室温」を選ぶと場所のプルダウンが現れ、この画面で図書館や201教室を切り替えられます。選択場所は提案画面と共通です。
- **みんなのひろば**：体感の投稿一覧。投稿フォームは上部ボタンを押したときだけボトムシートで表示。ボタンは一覧と一緒にスクロールし、下方向のスクロールには追従しません。

服管理タブはありません。写真は生成サンプルで、実際の利用者の履歴ではありません。カメラは画面確認用のサムネイルを受け取ります。

## 配色

寒色は柔らかい水色、暖色は柔らかいオレンジを使い、文字は濃い青・ブラウン系にしています。主要な文字と背景の組合せはコントラスト比4.5以上を確認しました。温度の表示色は画面側の仮ルールとして22℃未満を水色、それ以上をオレンジにしています。快適さ・服装の判定ロジックではありません。

## アイコン

アプリ内のベージュ・テラコッタ・水色に合わせた、シンプルなハンガーのマークです。ホーム画面・起動時・アプリ上部を同じマークに揃えています。PNG参照を使わずAndroid標準のベクターで構成し、通常・アダプティブ・Android 13以降のテーマ付きアイコンを用意しています。下部タブの選択状態は背景とラベルでも区別します。

## 表示・操作の範囲

サンプル会話と写真プレビューはメモリー上だけで保持します。端末内保存・サーバー保存・実際の投稿・AI評価・推薦学習は行いません。GPSは実装せず金沢固定です。写真選択時は10MB以下の画像を表示用に縮小して読み込みます。

温度フィルターは画面上の絞り込みだけです。「今の室温」は選択場所の室温と過去サンプルの室温、それ以外の温度条件は金沢の気温と過去サンプルの屋外気温を比較し、±2℃に入るものを表示します。

## 編集箇所

- `MainActivity.kt`：画面の枠組みと4タブ。
- `ClimaFitTheme.kt`：配色、共通カード・バッジ・選択欄。
- `OutfitScreens.kt`：提案と気温別コーデ。
- `ChatScreen.kt`：チャットと写真・カメラのUI。
- `CommunityScreen.kt`：ひろば一覧と投稿シート。
- `UiModels.kt`：表示モデルと固定サンプル。
- `ClimaFitViewModel.kt`：選択状態、画面内の会話サンプル、写真プレビュー。
- `docs/ui-handoff.md`：連携担当者向けの画面の引き継ぎメモ。

Kotlinファイルは `app/src/main/java/jp/climafit/app/` にあります。画像は `app/src/main/res/drawable-nodpi/` に同梱しています。

## 日本語入力

チャットとひろばの入力欄は日本語の入力言語ヒントを設定し、IMEの変換範囲を保持する `TextFieldValue` を使用しています。半角英数字への変換やASCII制限はありません。文字数上限は入力後の表示と送信可否で扱い、かな漢字変換中の入力を途中で切り捨てません。

エミュレーター側が英語キーボードだけの場合は、アプリの設定だけでは日本語入力できません。

1. エミュレーター内で **Settings → System → Keyboard → On-screen keyboard → Gboard → Languages** を開きます。
2. **Add keyboard → Japanese（日本語）** を追加します。メニュー名はAndroidのバージョンにより異なる場合があります。
3. 入力時に画面キーボードの地球儀キーまたはスペースキー長押しで日本語へ切り替えます。
4. 画面キーボードが出ない場合は、物理キーボードの設定で画面キーボードの表示を有効にします。

日本語キーボードがないシステムイメージの場合は、日本語入力対応IMEの導入が必要です。アプリからキーボードのインストールやシステム全体の入力言語の変更は行いません。
