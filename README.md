# LayeRoom（レイルーム）— 現在の機能一覧

LayeRoom（レイルーム）は、外気温だけでは分からない講義室の暑さ・寒さに着目し、大学で快適に過ごすための服選びを支えるアプリです。

金沢での利用を想定した、気温・室温と服装を組み合わせるAndroidアプリの**フロントエンド用UIプロトタイプ**です。Kotlin / Jetpack Composeで作成しています。

本READMEに現在の画面・操作・実装範囲をまとめています。アプリは固定サンプルで動作し、バックエンドへの通信、実際のAI処理、データ保存は実装していません。

## 1. 共通の画面・デザイン

- 下部タブは「提案」「コーデAI」「気温別コーデ」「みんなのひろば」の4つです。
- ベージュ・テラコッタ・水色を基本にした、柔らかく見分けやすい配色です。
- 温度の表示色は、仮のUIルールとして22℃未満を水色、それ以上をオレンジにしています。体感や服装を判定する計算ではありません。
- ホーム画面用アイコン・起動時・アプリ上部に、「L」を重ねたマークを設定しています。重ね着（Layer）と室内（Room）をイメージしたデザインです。Androidの通常・アダプティブ・テーマ付きアイコンに対応しています。
- 上部に「UIプレビュー」を表示し、更新アイコンを押すとサンプルデータであることを案内します。
- 場所の選択は画面間で共通です。図書館・201教室・学生食堂・実験室3から選べます。
- 旧版にあった「服管理」タブ・服の登録フォームはありません。

## 2. 提案タブ

### 表示する内容

- 今日の行き先を選ぶプルダウン。
- 写真付きの大きな服装提案カード。タイトル、説明、組み合わせる服を表示します。
- 「図書館の室温」「201教室の室温」など、選択場所名を含んだ室温と湿度。
- 「金沢の気温」。GPS取得は実装しておらず、金沢固定です。
- 室内の快適さ・不快指数のサンプル表示。

### できる操作

- 行き先を切り替えると、その場所に対応するサンプル室温・湿度・服装提案へ表示を切り替えます。
- 「写真診断・AI提案を使う」を押すと、コーデAIタブの入口へ移動します。チャットや文章入力はありません。

服装提案や不快指数はあらかじめ用意した表示データです。生成・判定・計算は行いません。

## 3. コーデAIタブ

最初に次の2つのボタンから選びます。**チャットの吹き出し・メッセージ入力欄・キーボード入力はありません。**

### A. 写真でコーデ診断

1. 「服の写真を撮る・選ぶ」を押します。
2. 「カメラで撮る」または「写真から選ぶ」を選びます。
3. 写真を画面で確認します。解除・別の写真への変更もできます。
4. 「この写真で診断する」を押します。写真未選択・読み込み中は押せません。
5. 診断結果・アドバイスの表示位置を示すサンプルカードを開きます。

- 文章の入力は不要です。
- 選択した画像は10MB以下を対象に、表示用に縮小して読み込みます。
- カメラは画面確認用のサムネイルを取得します。
- 診断ボタンはフロントエンドのアクションとして画像を受け渡します。現時点ではサーバーへ送信せず、AI評価も行いません。

### B. AIにコーデを提案してもらう

1. 選択場所の室温と金沢の気温を確認します。
2. **「今日の服装を提案して」** ボタンを押します。
3. フロントエンドのアクションに、固定プロンプト **`今日の服装を提案して`** を自動で設定します。
4. 写真付きの提案結果の表示サンプルを開きます。

- 自由入力や会話のやり取りはありません。
- 実際のプロンプト送信・AIからの提案取得はバックエンド連携後の担当範囲です。
- サンプル画像は、気温等から選び出したAIの結果ではありません。

### 結果画面・戻る操作

- 両方の結果カードに「このコーデを保存」を表示しますが、現在は保存しないことを案内するだけです。
- 左上の戻るボタンまたはAndroidの戻る操作で、2つの選択肢へ戻れます。
- フロントエンド側の受け渡し先は `LayeRoomViewModel.latestAiRequest` です。サーバーAPIの形式やエンドポイントを定義するものではありません。

## 4. 気温別コーデタブ

### 表示する内容

- 過去のコーデを想定したサンプル2件。
- コーデ写真、タイトル、日付、場所、屋外気温、室温。
- 写真は生成したサンプルであり、実際の利用者の過去の写真ではありません。

### 温度による絞り込み

| 条件 | 動作 |
| --- | --- |
| すべて | すべてのサンプルを表示 |
| 今の金沢 | 現在の金沢のサンプル気温に近い屋外気温のコーデを表示 |
| 今の室温 | 下に場所のプルダウンを表示。選んだ場所の室温に近いコーデを表示 |
| 温度を指定 | 下に数値入力欄を表示。入力した屋外気温に近いコーデを表示 |

- 温度の差が±2℃以内のサンプルを表示します。
- 「今の室温」では、この画面だけで図書館・201教室などを変更できます。選択場所は提案タブとも連動します。
- 指定温度の入力範囲は−50〜60℃です。入力が不正な場合や一致するコーデがない場合は、その旨を表示します。
- 絞り込みは画面内のサンプルに対する表示操作だけで、サーバー検索は行いません。

## 5. みんなのひろばタブ

### 一覧

- 場所、寒い・暑い・快適などの体感、コメント、投稿時刻を想定した表示サンプルを並べています。
- 寒い投稿は水色、暑い投稿はオレンジ、快適な投稿は緑のバッジで区別します。

### 投稿フォーム

1. 上部の「いまの体感を投稿する」を押します。
2. 下から投稿シートを開きます。
3. 場所・体感・ひとことを入力します。
4. 「投稿する」を押すと、プレビューのため送信・保存しないことを案内します。

- 投稿フォームは一覧に常駐しません。
- 投稿ボタンは一覧と一緒にスクロールし、画面下へのスクロールには追従しません。
- コメントは1〜500文字の範囲で投稿ボタンを有効にします。日本語の変換中の状態を保持します。
- チャットを廃止しても、この投稿フォームの文章入力は残しています。

## 6. 実装済み・未実装の境界

| 項目 | 現在の状態 |
| --- | --- |
| 4タブと画面遷移 | 実装済み |
| 場所選択・温度による画面の絞り込み | サンプルデータで実装済み |
| 写真撮影・選択・プレビュー・解除 | UI用に実装済み |
| 写真診断の操作 | 写真をフロントエンド内のアクションへ渡すまで |
| ワンタップの服装提案 | 固定プロンプトをフロントエンド内のアクションへ渡すまで |
| 結果・保存・投稿画面 | 表示サンプル。実際の保存・投稿はなし |
| チャット・自由入力によるAI相談 | 削除済み |
| センサー値・天気の取得 | 未実装、固定サンプル |
| GPS・現在地取得 | 未実装、金沢固定 |
| 不快指数の計算・服装の判定 | 未実装、固定サンプル |
| AIへの送信・写真評価・提案生成 | 未実装 |
| 過去データに基づくAI推薦 | 未実装 |
| ログイン・認証・データベース | 未実装 |
| 端末内保存・サーバー保存・利用者間の共有 | 未実装 |

写真・表示用アクション・結果の表示状態は、アプリ実行中のメモリー上でのみ扱います。アプリ終了後の保存は行いません。API通信や保存方法の仕様はバックエンド担当者が決める範囲です。

## 7. Android Studioで開く・更新する

1. `settings.gradle.kts` がある **`codex_test` フォルダー**を開きます。
2. 既にクローン済みなら **Git → Pull** で `main` を更新します。再クローンは不要です。
3. 必要に応じて **File → Sync Project with Gradle Files** を実行します。
4. 上部で `app` と端末を選択し、**▶ Run** を押します。

この変更のバージョンは **1.5** です。初回同期にはネット接続、JDK 17以上、Android SDK Platform 35が必要です。ホームに旧アイコンが残る場合は、アプリ一覧のLayeRoomとホームのショートカットを分けて確認してください。

| 構成 | バージョン |
| --- | --- |
| Android Studio | Meerkat以降、Otter 3対応 |
| Gradle | 8.11.1 |
| Android Gradle Plugin | 8.9.2 |
| Kotlin | 2.1.20 |
| Compose BOM | 2025.03.01 |
| 最小Android API | 26 |
| compile / target SDK | 35 |

## 8. 主なファイルと検証コマンド

Kotlinファイルは `app/src/main/java/jp/climafit/app/` にあります。

| ファイル | 役割 |
| --- | --- |
| `MainActivity.kt` | アプリの枠組みと下部タブ |
| `LayeRoomTheme.kt` | 共通の配色・カード・バッジ・プルダウン |
| `OutfitScreens.kt` | 提案と気温別コーデ |
| `AiScreen.kt` | AIの2つの入口、写真診断・ワンタップ提案、結果サンプル |
| `CommunityScreen.kt` | ひろばと投稿フォーム |
| `JapaneseTextInput.kt` | ひろばで使う日本語キーボード向け設定 |
| `UiModels.kt` | 表示モデル・固定プロンプト・サンプルデータ |
| `LayeRoomViewModel.kt` | 選択状態・写真読込み・UI内のアクションと結果表示状態 |
| `app/src/test/java/jp/climafit/app/FrontendUiTest.kt` | アイコン・AI画面操作・日本語投稿のテスト |

Windows：

```bat
gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

macOS / Linux：

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

APKビルド・Android Lint・自動テスト5件が成功しました。テストではアイコン描画、AIの2つの入口、固定プロンプトの受け渡し、写真の有無による診断操作、日本語投稿入力を確認しています。

自動テストではRobolectricを使い、Android 35相当の環境で確認します。実機・利用者のエミュレーター固有のカメラ・ランチャー・キーボードの挙動は別途確認が必要です。

表示名・プロジェクト名はLayeRoomに統一しています。既存アプリへ上書き更新できるよう、内部のアプリID・パッケージ名 `jp.climafit.app` は維持しています。
