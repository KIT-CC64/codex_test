# UIの引き継ぎメモ

この変更はKotlin / Jetpack Composeによるフロントエンドの画面モックのみです。
APIエンドポイント・認証・通信形式・AI処理・データの保存方法はここでは定義・実装しません。

## バックエンド担当者に渡す画面

- 提案：選択した場所の室温・湿度、外気温、不快指数、服装提案のテキストと重ね着リストを表示。
- コーデAI：写真選択とプレビュー。診断開始ボタンは案内のみ。
- 記録：日時・場所・室温・外気温・提案タイトル・説明文のサンプル一覧。温度による表示絞り込みあり。
- 口コミ：場所・体感・コメントの入力欄、投稿ボタン、サンプル一覧。
- 服管理タブはありません。

`UiModels.kt` のデータクラスは表示項目をまとめたものです。サーバー側のモデルやJSON形式を指定するものではありません。
`PreviewData` は見た目の確認用で、提案の判定や不快指数の計算は行いません。

## 未実装

センサー取得、天気取得、AI診断、服装の判定、不快指数の算出、認証、API通信、投稿・記録の送信、端末内保存・サーバー保存。
記録・投稿・診断のボタンには案内メッセージだけを設定しています。バックエンドの連携方式が決まった後、担当者が対応する処理を接続してください。
